## 🇷🇴 Română

Un addon premium pentru Stremio care aduce subtitrări românești perfect sincronizate direct de pe RegieLive, cea mai mare bază de date din România.

### ✨ Funcționalități
- 🇷🇴 **Bază de date imensă**: Preluare rapidă direct de pe RegieLive.
- 🆓 **Fără conturi sau API Keys**: Funcționează instant, fără nicio pagină de configurare enervantă.
- 🎯 **Algoritm Match Suprem**: Motor de recunoaștere avansat cu peste 550 de grupuri (Release Groups) pentru o sincronizare perfectă cu fișierul tău video.
- ⭐ **Sortare Inteligentă**: Alege automat și prioritizează subtitrările care au cea mai mare notă din partea comunității.
- 🎬 **Suport Complet**: Funcționează impecabil atât pentru filme, cât și pentru seriale.
